# Millio — MVP feature spec

> *"Grain by grain, the chicken fills its belly."*
> A gamified net worth tracker that counts down to your million harvest.

---

## Concept glossary

| Term | Meaning |
|---|---|
| **Silo** | A named asset (savings account, property, investment fund, etc.) |
| **Net worth** | The sum of all silo current values |
| **Monthly contribution** | How much the user adds across all silos per month |
| **Harvest** | Reaching the $1,000,000 goal |
| **ETA** | Projected month and year of the harvest |

---

## Domain: onboarding

First-run experience. Collects the minimum data needed to power the countdown and ETA projection.

### Step 1 — Welcome
Introduce the app concept. One screen, minimal copy. CTA: "Let's plant your first grain."

### Step 2 — Current net worth
User adds their first silos. For each silo:
- **Name** (e.g. "Nubank", "Apartment", "XP Investimentos")
- **Type** — `cash` | `property` | `investment`
- **Current value**
- **Yearly return rate** — one of:
  - User enters a known rate (e.g. 10.5%)
  - User picks a preset: `conservative (6% a.a.)` | `moderate (10% a.a.)` | `aggressive (15% a.a.)`
  - `None / I don't know` → treated as 0% (no growth, contributions only)

User can add multiple silos. Must add at least one to proceed.

### Step 3 — Monthly contribution
How much do you add to your silos every month, in total?
- Single number input
- Can be 0 (some users are in growth phase via returns only)

### Step 4 — Goal (optional)
Target amount. Defaults to **$1,000,000**. User can change it now or later in settings.

Onboarding is skipped on subsequent app opens. All data collected here seeds the `portfolio` and `projection` domains.

## Domain: portfolio

### Silo model
```
Silo {
  id: string
  name: string
  type: 'cash' | 'property' | 'investment'
  currentValue: number
  yearlyReturnRate: number        // 0 if unknown/none
  createdAt: Date
}
```

### Net worth total
Sum of `currentValue` across all silos. Recomputed on every silo update.

### Update a silo value
User sets the new current value of a silo. The app computes the delta:
`delta = newValue − previousValue`
Net worth and countdown update instantly.

### Update history log
Every silo update is stored:
```
SiloUpdate {
  siloId: string
  previousValue: number
  newValue: number
  delta: number
  timestamp: Date
}
```
Powers the ETA projection and the history view.

### Add / edit / delete a silo
User can manage silos at any time after onboarding. Deleting a silo removes its value from net worth.

## Domain: projection

### ETA calculation
Projects the month and year the user reaches their goal.

**Inputs:**
- Current net worth
- Goal amount (default $1,000,000)
- Monthly contribution
- Each silo's current value + yearly return rate

**Model:**
Simulate month by month:
1. Apply each silo's monthly compound return: `value × (1 + yearlyRate/12)`
2. Add the monthly contribution to net worth
3. Repeat until net worth ≥ goal or max 600 months (50 years)

**Output:**
- Number of months to goal
- Projected arrival month + year
- Requires net worth > 0 to calculate
- If goal is unreachable within 50 years → show "Add more or increase your returns"

### Monthly growth rate (for hype moments)
Average net worth delta across the last 3 updates. Used to power celebratory messages.

## Domain: gamification

### Milestones
Triggered the first time net worth crosses each threshold. Never re-triggers.

| % of goal | Name | Hype message |
|---|---|---|
| 1% | First grain in the silo | The chicken has started eating. |
| 10% | 10% Millionaire | One tenth of the way. The silo is waking up. |
| 25% | Quarter harvest | One quarter done. You're seriously doing this. |
| 50% | Halfway there | HALFWAY. Your silos are half full. Don't stop now. |
| 75% | Almost dangerous | 75% in. You can almost smell the harvest. |
| 90% | Final sprint | 90%! Last stretch. The million is right there. |
| 100% | HARVEST TIME | YOU DID IT. YOU ARE A MILLIONAIRE. 🌽 |

### Hype moment
Fires after any update that increases net worth. Does **not** fire on downward corrections.

Message examples (pick contextually):
- "You just cut X weeks off your ETA!"
- "Your silos grew $X this month!"
- "Best update yet — the grain is piling up!"
- "At this pace, harvest is in [month, year]."

---

## Domain: dashboard

### Countdown display
Hero element. Always visible.
- **"Only $X to go!"** — big, front and center
- Progress bar: current net worth / goal
- Percentage label: "You're 23% there"

### ETA display
- "At your current pace: **March 2029**" (X months away)
- Updates on every silo change

### Silos summary
- List of all silos with current value and type icon
- Quick-tap to update any silo value

### Net worth total
Displayed below the countdown. "Your silos hold $230,000."

## Out of scope (MVP)

- Bank sync / open finance
- Expense tracking
- Per-silo contribution split
- Monthly streak tracking
- Net worth chart over time
- Multi-currency support
- Social / sharing features
